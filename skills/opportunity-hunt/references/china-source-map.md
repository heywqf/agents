# 中国市场来源地图

在研究中国具体买方、平台、供应链、政策或本地渠道时，按要证明的结论选择来源。这里列的是起点，不是必须逐站检查的清单，也不保证任何平台持续公开同样的数据或允许相同访问方式。

## 按问题选择来源

| 要回答的问题 | 可优先检查的来源类型与示例 | 应提取什么 | 主要局限 |
|---|---|---|---|
| 谁已经在付钱 | 当前价格页、服务菜单、淘宝/闲鱼/京东/拼多多/抖音等商品与服务报价、采购成交记录、合同或经营者账单 | 具体报价、付款条件、成交或采购行为、退款和交付范围 | 标价不等于成交价；销量、评价和榜单口径可能不透明或受推广影响 |
| 企业正在为何投入 | BOSS 直聘、智联招聘、猎聘等当前职位，外包需求和供应商招募 | 任务、岗位数量、薪酬或预算、地点、持续时间、资质要求 | 招聘只证明计划投入，不能证明客户会购买拟议报价 |
| 供给与履约成本 | 1688、产业带供应商、批发市场、物流和平台官方费率、设备租赁或服务商报价 | 起订量、含税与否、样品价、交期、运费、损耗、售后和账期 | 页面报价可能是引流价；必须核实到岸成本、质量和真实交易条件 |
| 客户在哪里反复受阻 | 小红书、知乎、贴吧、黑猫投诉、应用商店评论、产品支持社区、行业微信群或论坛中用户提供的记录 | 最近一次真实经历、替代做法、频率、损失、退款、迁移和付费痕迹 | 爆款、推广、删帖和幸存者偏差严重；互动量不是付款证据 |
| 新经营者能否进入 | 平台新店和近期评价、近期成立或变更的经营主体、服务商案例、客户迁移记录 | 开业时间、首批订单或客户、渠道来源、评价历史、持续经营迹象 | 国家企业信用信息公示系统、企查查或天眼查只能证明主体或公开记录，不证明盈利 |
| 公共或机构资金是否存在 | 中国政府采购网及地方公共资源交易平台、主管部门公开采购与中标信息、学校医院或国企公开采购页面 | 采购主体、预算或成交额、资质、交付、账期和中标者类型 | 政府预算不是经营者可获得收入；资质、保证金、关系和回款可能构成硬门槛 |
| 渠道是否真的可用 | 平台商家规则、收费和准入页面，搜索结果与广告位，应用商店、插件目录、小程序生态和行业协会名录 | 准入条件、抽成、流量入口、商业意图、近期规则变化和首批客户路径 | 可见不等于可低成本触达；搜索排名和推荐流量不可假设可复现 |
| 钱如何合法到账 | 支付服务商、交易平台和银行的官方支持地区、商户主体与结算条款，税务和外汇主管部门公开规则 | 可用主体、币种、支付方式、费率、准备金、拒付、冻结、提现、结算周期、税务和结汇条件 | 能注册账户不等于能稳定收款或提现；规则和主体资格会变化，必要时提示专业复核 |
| 线下价格、客流和供给密度 | 公开价目、地图与商户目录、公开场所分时观察、经营者真实考虑购买时的低负担询价 | 报价区间、排期、可见客流、峰谷时段、竞品与供给密度 | 单点观察受时段、天气和季节影响；不得假扮买家、虚构需求、秘密进入非公开区域或违规录音录像 |
| 竞品是否存续及如何经营 | 竞品官网和门店、价格与条款、国家企业信用信息公示系统、商业企业信息平台、招聘和客户评价 | 当前报价、交付边界、成立与存续、人员投入、迁移成本和结构性缺口 | 注册资本、融资、员工数和媒体曝光不能直接推出收入或利润 |
| 政策或平台规则是否允许 | 国务院及主管部门、地方政府、监管机构、国家标准全文公开渠道、平台官方规则与公告 | 现行文本、生效日期、适用对象、许可和禁止事项 | 优先使用当前一手文本；媒体解读和旧页面只能作为线索，必要时提示专业复核 |

## 使用规则

- 先写清楚要支持的结论，再选来源；不要因为某个平台容易搜索就让它定义市场。
- 价格、规则、平台入口和供给条件必须注明检查日期。登录墙、验证码、地区限制或无法访问时如实说明，不得绕过访问控制或根据搜索摘要补全页面内容。
- 对会改变状态或重大投入的结论，在成本合理时使用至少两种独立来源类型交叉检查。多个转载同一公告、多个店铺复制同一供应商文案，不算独立证据。
- 社区抱怨可以支持问题信号，商品和职位可以支持商业信号；只有经营者自己的真实报价、付款、交付和贡献利润记录才能提升对应的实测维度。
- 对跨境机会使用目标市场的一手来源、当地交易渠道和规则，不得把中国平台行为直接外推到海外，也不得用海外社区替代中国买方证据。
